## Правила яруса 1 (P1/P2)

### T4 — `no-cross-slice-import` (P1)
Импорт между слайсами одного слоя запрещён, опция `allow: []`. `stratum-rules`. **deps:** T2. **verify:** ловит реальные feature→feature на web-client; список не шумный (выборка подтверждает). **M**

### T5 — `enforce-public-api` (P1)
Запрет глубоких импортов мимо `index.ts` по `import_depth`. `stratum-rules`. **deps:** T1c, T2. **verify:** `../archive-export/model/store` падает, `../archive-export` ок. **M**

### T6 — `require-public-api` (P1)
Slice без `index.ts` флагается. `stratum-rules`. **deps:** T2. **verify:** слайс без barrel — нарушение; с barrel — чисто. **S**

### T7 — `private-to-siblings` (P1)
Переработка `visibility-scope`: path-jump detection, конфиг имён (дефолт `_shared`,`_internal`). `stratum-rules`. **deps:** T2. **verify:** `permissions/→admin/_shared/` ок, `infrastructure/→permissions/_shared/` падает. **M**

### T8 — `deep-module` rework (P2)
Pass-through detection (доля публичных экспортов = ре-экспорт чужого, основной сигнал) + ratio интерфейс/реализация (вторичный); прокси-природу писать в сообщении; severity info/warning. `stratum-rules`. **deps:** T1a, T1b. **verify:** 1 экспорт над 10 файлами = deep; ре-экспорт-барель = shallow. **M**

### T9 — `instability` (P2)
`I = Ce/(Ca+Ce)` + флаг SDP-нарушения (зависит от более нестабильного). `stratum-graph` (метрика) + `stratum-rules`. **deps:** — (∥now, нужен только граф). **verify:** метрика на узле совпадает с ручным подсчётом на fixture. **M**

### T10 — `miller-limit` rework (P2)
Рекурсия по уровням контейнеров + homo/hetero детект; `maxHeterogeneous: 6` / `maxHomogeneous: 20`, конфигурируемо. `stratum-rules`. **deps:** — (граф/иерархия есть). **verify:** `permissions/` (7 однотипных таблиц) НЕ флагается; 7 разнотипных — флагается. **M**

### T11 — `insignificant-slice` (P2)
Slice с fan-in ≤1 флагается. `stratum-rules`. **deps:** T2. **verify:** слайс с одной/нулём ссылок — нарушение. **S**

### T12 — `config-paths-exist` (P2)
Валидация: `layer.path` указывает на существующую папку. `stratum-config`. **deps:** — (∥now). **verify:** несуществующий путь → ошибка конфига с понятным сообщением. **S**
